## 2. 实际数据库结构

本机项目库 `management-system` 的三张表均已存在，核对时三表业务记录均为0。新增表0张；修改表1张：经用户确认，仅为 `resource_category` 增加 `description VARCHAR(1000) NULL`。迁移执行并重跑成功，没有重建、物理删除或修改原约束。最终库仍为11张表。

| 表 | 最终字段 |
|---|---|
| `course` | `id BIGINT UNSIGNED` 自增主键；`course_code VARCHAR(40)` 非空唯一；`name VARCHAR(120)` 非空；`description VARCHAR(1000)` 可空；`status VARCHAR(16)` 默认ACTIVE；`created_at/updated_at DATETIME(3)` 非空 |
| `ideological_element` | `id BIGINT UNSIGNED` 自增主键；`name VARCHAR(100)` 非空唯一；`description VARCHAR(1000)` 可空；`status VARCHAR(16)` 默认ACTIVE；`created_at/updated_at DATETIME(3)` 非空 |
| `resource_category` | `id BIGINT UNSIGNED` 自增主键；`name VARCHAR(80)` 非空唯一；新增 `description VARCHAR(1000)` 可空；`status VARCHAR(16)` 默认ACTIVE；`created_at/updated_at DATETIME(3)` 非空 |

状态均限定为 `ACTIVE`/`INACTIVE`，不是用户状态中的 `DISABLED`。保留既有唯一键、`(status,name)` 索引、CHECK 及教学资源关联的 `ON DELETE RESTRICT`。创建时间默认当前毫秒时间，更新时间由数据库更新时自动刷新。新增默认启用；编辑只改编号/名称/说明，启停使用独立接口。去除名称/编号前后空白后校验；停用不释放原唯一值。

新库使用更新后的 `schema.sql`；旧库执行 `database/migrations/002-resource-category-description.sql`。`CREATE TABLE IF NOT EXISTS` 不会自动给旧表增加字段，不能代替迁移。

## 3. 接口与权限

下表 `{type}` 只能是 `courses`、`ideological-elements`、`resource-categories`，共15个“方法+路径”接口组合。

| 方法、路径 | 功能 | 权限 |
|---|---|---|
| `GET /api/{type}` | page/size 分页、keyword 查询、status 筛选；返回 items/total/page/size | ADMIN |
| `POST /api/{type}` | 新增，默认ACTIVE | ADMIN + CSRF |
| `PUT /api/{type}/{id}` | 修改基础信息 | ADMIN + CSRF |
| `PATCH /api/{type}/{id}/status` | 启用/停用 | ADMIN + CSRF |
| `GET /api/options/{type}` | 只读ACTIVE选项；id/name，课程另含courseCode | 三类已登录角色 |

管理接口同时使用 URL 授权和 `@PreAuthorize`；教师、学生不能通过GET管理列表绕过选项范围。options 固定使用ACTIVE条件，即使请求附加 `status=INACTIVE` 也不返回停用数据。分页限制 page≥1、1≤size≤100；关键词上限120字符，LIKE中的 `%`、`_`、`!` 在Repository中转义。课程搜索匹配编号或名称，元素/分类匹配名称。

没有 DELETE 接口；管理员请求DELETE返回405及统一 `METHOD_NOT_ALLOWED`。不存在ID返回404；字段或状态无效返回400；重复编号/名称返回409；未登录返回401；越权/缺CSRF返回403。仍使用 `{code,message,data}`，不暴露SQL或数据库连接信息。

1. 沙箱阻止Maven/Vite写构建临时目录：通过正常权限审批重新运行，测试和构建通过，不修改安全设置。

5. 测试输出包装器曾用数组的 `-notmatch` 作完成判断，虽然288项已通过却误报失败：改为检查匹配结果是否存在；加入第二页断言后，最终两轮均300项通过且退出码0。
