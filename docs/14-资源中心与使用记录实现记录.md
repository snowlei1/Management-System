## 2. 数据库最终结构与语义

实际库和schema核对后仍11张表。新增表0、新增字段0、新增索引0、迁移0，schema.sql没有变更。仅沿用既有表写业务测试数据。

| 表 | 现有字段与关键约束 | 最终语义 |
|---|---|---|
| favorite | id BIGINT UNSIGNED自增PK；user_id/resource_id同类型非空FK；active BOOLEAN默认TRUE；created_at/updated_at DATETIME(3)默认当前时间，后者ON UPDATE；唯一(user_id,resource_id)；索引(resource_id,active)；外键RESTRICT | 一用户/资源始终一条当前收藏关系。首次收藏INSERT，再收藏UPSERT为TRUE；取消UPDATE为FALSE，不物理删除、不另建取消日志。created_at为首次时间，updated_at为实际变化时间，不承诺每次幂等操作刷新 |
| browse_record | id BIGINT UNSIGNED自增PK；user_id/resource_id非空FK；browsed_at DATETIME(3)默认当前时间；索引(user_id,browsed_at)、(resource_id,browsed_at)；外键RESTRICT | 每次成功GET普通已发布详情追加1条访问事件，打开/刷新均可计数，不是UV或独立人数；失败回滚；HEAD不计 |
| download_record | id BIGINT UNSIGNED自增PK；user_id/resource_id非空FK；downloaded_at DATETIME(3)默认当前时间；索引(user_id,downloaded_at)、(resource_id,downloaded_at)；外键RESTRICT | 身份、可见性与文件有效性校验后，准备正常返回附件响应时追加1条下载请求事件；多次请求可多条，不保证客户端完整接收；HEAD不计 |

三个user_id均从当前Session取值，不能由body/query伪造。列表、分页、options、我的收藏、预览、收藏/取消不额外生成浏览事件；管理员审核详情/附件读取不生成普通浏览/下载。未登录、越权、非公开状态、缺文件和文件校验失败不记下载。

## 3. 可见性、查询与并发

全部普通入口在SQL固定：

```sql
r.status = 'APPROVED'
AND r.deleted_at IS NULL
AND r.published_at IS NOT NULL
```

包含列表、详情、预览、下载、收藏/取消以及我的收藏。DRAFT/PENDING/REJECTED、已软删除资源即使知道ID也统一404。传status=DRAFT不能扩大范围。ADMIN普通API为403，未登录读取401；ADMIN只走原审核API，不借此获得资源使用角色。

关键词匹配标题或简介；转义LIKE的%、_、!，参数化绑定。courseId/categoryId/elementId可组合，元素以EXISTS筛选。page从1起、size为1—100、关键词最多200字符，默认10条。排序为published_at DESC,id DESC，发布时间相同也以ID确定次序。我的收藏额外限定当前Session用户和active=TRUE。

列表使用COUNT、元数据/当前收藏JOIN、元素IN批量查询，非空页固定3次查询，不逐资源取元素。公开VO只含展示数据，不含storageKey、服务器路径、auditRecords、submissionNo等私有工作流字段。不为了列表展示另建缓存或冗余计数字段，本阶段未展示全套聚合计数。

2026-10-05 21:55实际EXPLAIN：无筛选查询使用idx_resource_public（预估10行），收藏关联使用uk_favorite_user_resource，其余基础表主键关联；课程68/分类64/元素68组合查询使用idx_resource_public（预估3行）和关联联合主键。排序出现Using filesort，现有索引不覆盖发布时间排序，前导通配LIKE也不宣称由title索引加速。上述是小规模测试数据的查询计划，不是性能基准；没有性能瓶颈证据，本轮不新增索引。

单资源操作事务内先只对可见teaching_resource行FOR SHARE，再读元数据。收藏不先给favorite行加共享锁，避免同用户并发UPSERT锁升级死锁；唯一键落实一条关系。重复收藏、重复取消、取消无关系均200幂等。真实双线程MySQL测试两次收藏均成功，关系只有1条，取消后再次收藏复用原关系ID。浏览/下载插入后受控抛异常的真实事务测试均回滚事件，不改变资源发布状态。

## 4. API与页面

新增7个业务接口，均TEACHER/STUDENT；URL、方法级和服务层角色检查同时存在。

| 方法/路径 | 行为 |
|---|---|
| GET /api/resources | keyword/courseId/categoryId/elementId/page/size组合检索 |
| GET /api/resources/{id} | 公开详情及当前收藏状态，成功GET记浏览 |
| GET /api/resources/{id}/preview | PDF/PNG/JPEG安全预览，不记使用事件 |
| GET /api/resources/{id}/download | 安全附件下载，准备响应记下载请求事件 |
| POST /api/resources/{id}/favorite | CSRF保护的幂等收藏 |
| DELETE /api/resources/{id}/favorite | CSRF保护的幂等取消，非物理删除 |
| GET /api/favorites | 我的有效且仍公开收藏，分页 |

JSON沿用{code,message,data}；文件成功返回字节，错误沿用统一JSON及合理HTTP状态。普通VO和附件响应不暴露受控目录。后端复用LocalResourceFileStorage.readVerified：UUID受控键、目录边界/符号链接、可读文件、大小、白名单MIME/扩展名与基本内容特征重新核验，uploads未作为静态目录公开。

新增/resources、/resources/:id、/favorites三条路由。资源中心与我的收藏复用PublishedResourceListView；详情使用PublishedResourceDetailView。教师/学生菜单开放资源中心与我的收藏，ADMIN不显示且路由拒绝。详情收藏只更新本地favorite，不为刷新状态重复GET详情。

PDF复用ReviewPdfPreview及本地PDF.js worker，PNG/JPEG使用授权Blob，卸载释放Blob URL。Office明确提示“该格式暂不支持浏览器内预览，请下载后查看”，后端preview400，不上传第三方转换。下载使用带Session的同源受保护链接，后端attachment、正确MIME、UTF-8中文原文件名、no-store、nosniff、CSP sandbox；默认DENY framing头保留，没有为了PDF嵌入关闭安全头。
