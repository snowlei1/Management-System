日期：2026-10-06。稳定起点：`f418175c03892593df140912d045009b4fab4b62`。

## 1. 范围与不变基线

本阶段只修改前端视觉、布局、信息层级与展示文案；没有修改后端、数据库、API封装、路由权限规则、Session、CSRF、HttpOnly Cookie、BCrypt、资源四状态、submission_no、审核规则、文件规则和统计事件语义。没有加入AI、推荐、通知、社交、考试等业务。任务书、开题报告、论文及用户已有截图材料未纳入本次修改或提交。

依赖及稳定技术版本不变：Spring Boot 3.5.7、Spring Security 6.5.6、JDK 21.0.11、Spring JDBC、MySQL 8.0.39；Vue 3.5.13、Vue Router 4.5.1、Vite 6.3.5、Node.js 22.14.0、pnpm 11.25.0、ECharts 5.6.0、@lucide/vue 1.52.0。没有新增依赖或大型UI框架。

## 2. 旧视觉问题与新色彩体系

旧版以青绿色为主，大量页面采用同尺寸白卡、相似标题/筛选结构，角色首页与课程/专题列表缺少差异。本阶段保留既有组件和表单基础样式，在 `design-system.css` 增加品牌与布局层，不重新推翻前端架构。

## 3. 页面与三角色差异

| 页面/角色 | 本阶段布局变化 |
|---|---|
| 登录 | 左品牌文字、书本/校园抽象图形，右380px登录卡；无外部图片、旗徽或宣传性文案 |
| ADMIN工作台 | 4个主指标、4个次级指标，左待审右环图，下方快捷管理及三种分布；突出治理事项 |
| TEACHER工作台 | 四状态整条概览，左最近编辑与已发布资源使用表，右驳回原因及建设入口；新建为主操作 |
| STUDENT门户 | 小型暖米Hero和检索入口；最新资源横向列表，课程为简洁条目，专题为米色栏目，历史/收藏为缩略列表 |
| 资源中心 | 紧凑开放式工具栏，桌面2列宽卡；文件图标、标题、两行简介、不同类型Tag与底部教师/时间信息 |
| 课程导航/详情 | 编号及教学信息卡；详情为课程信息、真实相关元素及资源列表 |
| 思政专题/详情 | 暖米栏目、宋体专题标题、序号及细线；详情为专题说明、真实关联课程及教学资源 |
| 资源详情 | 文章式头部，预览约70%与文件/使用侧栏约30%；简介独立，同课程/元素关联为紧凑横向条目 |
| 审核详情 | 材料左、操作右，真实审核历史移至下方；金色轮次、红色驳回、绿色通过，审批意见不做聊天气泡 |
| 用户/基础数据/台账/教师资源 | 保留清晰表格及既有操作，暖色表头、克制边线和小型操作，不加装饰性业务 |
| 统计 | 统一标题、轴字体和tooltip，容器取消重阴影；状态环图与课程/分类/元素分布用不同有限配色 |

减少Card的方式：门户横向列表共享分割线；专题不套白色圆角Card；最近浏览、收藏、快捷入口用列表或细边线；工作区采用直边顶线。资源卡、管理表单与Modal保留必要容器，主要圆角6—10px。并非完全取消Card，也不以“零模板感”作为可量化测试结果。

课程列表原API只提供编号、名称、简介及资源数，不提供每个课程的相关元素；本阶段没有修改接口或批量逐项请求详情。列表明确提示进入课程查看相关元素，详情显示真实关联，不伪造标签。专题序号是当前展示顺序，不是评分。首页课程按已发布资源数降序、ID升序展示前4项，并明确不是质量排名或推荐。

## 6. 响应式与视觉自检

- 1440×900：16个重点页面实际截图，尺寸已用图片元数据检查；长详情和统计另存完整页辅助证据，主清单仍为视口截图。
- 1366×768：资源详情与管理员工作台检查，document.scrollWidth为1351，不超过1366。
- 390×844：学生门户、专题、资源详情、教师资源表、管理员分类表、审核历史、统计图检查。稳定状态document.scrollWidth为375/390，不超过视口；导航抽屉可打开且选路由后收起。PDF canvas缩至343px；统计图ResizeObserver稳定后宽305px、高235px。表格720px在内部table-wrap横滚，不把整个页面撑宽。
- 部分viewport改变后第一帧会保留旧canvas尺寸，观察布局稳定后再次核验与截图，未把过渡帧当作最终结果。

视觉自检结论：门户、建设工作台与治理工作台有不同节奏；专题栏目与课程教学卡明确区分；红色用于导航/标题/主操作，未做满屏红金。仍复用资源卡、表格等基础组件，但没有让每个模块都成为同尺寸白色圆角Card。数据较少的审核筛选/管理页仍有自然留白，不填假条目。是否“像AI模板”属于主观评价，本轮已减少重复布局，不作完全消除的绝对承诺。
