## 1. 范围与基线

- 保留 Session、HttpOnly Cookie、CSRF、BCrypt、ADMIN/TEACHER/STUDENT 及原接口语义。
- 保留 DRAFT/PENDING/REJECTED/APPROVED、submission_no、本人资源权限和审核事务。
- 草稿允许 0..N 个有效思政元素；提交审核仍要求至少 1 个且全部有效。学生仍不能上传。
- 公开资源仍须同时满足 APPROVED、deleted_at IS NULL、published_at IS NOT NULL；停用基础数据不抹去历史关联。
- 没有数据库表、字段、索引或迁移变更，仍为 11 张表，database/schema.sql 未改动。
- 没有增加下架、撤回、版本管理、AI、推荐、社交、教学安排或成绩业务。任务书、开题报告和论文 Word 材料未执行写操作；用户原有未提交材料保留并排除本阶段提交。

## 4. 页面与交互实现

### 4.1 统一设计系统

design-system.css 定义青绿色主色、浅灰背景、白色卡片、圆角、边框、字号层次、按钮、表单、状态 Badge、Tag、表格、分页和 Focus/Hover。AppLayout 使用分组导航、明显 active 状态、面包屑、用户姓名/角色/头像占位、退出入口、桌面折叠和窄屏抽屉。路由切换回到页顶，浏览器后退使用保存位置。

新增 AppFeedback、LoadingState、EmptyState、AppIcon、ResourceCard、StatisticsCharts。API 封装保留 Session/CSRF 逻辑，统一错误 Toast 和非认证写操作成功提示；常规 auth/me 未登录响应不制造错误 Toast。保存、审核、收藏等使用 busy 状态防重复；确认操作仍为页面内弹窗，不引入原生 alert/confirm。初始加载数量显示“—”，不把尚未读取的数量写成 0。

### 4.2 三类首页

- 管理员：8 项真实概览、最近待审核资源至多 5 条及审核入口、快捷操作和 4 个统计图。最近待审核按真实 updated_at/ID 倒序，PENDING 状态下该时间表示本轮提交时间；不伪造独立提交事件。
- 教师：本人四状态数量、最近更新至多 5 条、真实驳回原因/时间、最近 5 份已发布资源的浏览/下载/当前收藏数。四个快捷入口放在待处理卡片中，减少无驳回时的无意义留白；驳回数量大于 0 时红色强调。
- 学生：资源门户 Hero、实际标题/简介检索、最新 6 份资源卡、课程导航、思政专题、本人最近浏览和收藏。无假通知、在线人数或增长趋势。

### 4.3 资源发现与使用

资源中心使用关键词/课程/分类/元素筛选、筛选 Tag、重置及每页 9 项卡片。卡片包含文件类型、标题、简介摘要、课程、分类、元素、教师、发布时间和真实收藏状态。收藏页复用卡片；取消后刷新有效收藏列表。

详情采用内容与文件信息两栏；PDF/PNG/JPEG 使用原授权预览，Office 明确提示下载查看。展示真实浏览事件数、下载请求数和当前收藏数；固定同课程/相同元素关联各至多 6 条，排除当前资源并只展示公开资源，不称作推荐。停用课程的公开历史资源仍可使用，但不链接到仅启用课程导航。

历史页按用户 Session 身份和事件时间/ID 倒序，每页 10 项，不接收客户端 userId 作为身份。经用户确认，页面仅展示当前仍公开资源；原始事件不删除，管理员累计浏览/下载继续包含软删除资源历史。下载记录不保证客户端完整保存文件。

### 4.4 教师建设与管理员审核

教师列表增加四状态 Tab/真实数量、Badge、最新驳回原因，仍按原状态允许操作。新建/编辑表单分为基本信息、资源归属、思政标注、附件；元素为 Tag 多选，附件支持拖拽/点击选择、文件卡和替换，保留白名单与 20 MiB 上限。

审核列表有真实状态数量/Tab与原查询条件。详情约 65/35 两栏，左侧资源和授权附件，右侧审核信息/操作与 Timeline。时间轴只用真实 auditRecord/submissionNo 展示轮次、管理员、结论、原因及审核时间，不补造教师修改或历史提交时间。非待审状态不显示重复审核按钮。

台账仅查看公开资源组织信息、计数和原审核历史；支持关键词、课程、分类、教师及分页，无下架、编辑或新的写接口。

### 4.5 统计图

保留原所有准确卡片和完整分布表，在表格之前增加资源状态环形图、课程/分类/元素水平柱状图。分布图展示前 6 个非零项；完整数据、停用历史关联和零项仍在原分页表中。多元素关联合计不等于资源总数，不解释为综合评分、学习效果或用户人数。切换页面释放 ECharts 实例，视口变化自动 resize。

## 5. 新增只读 API

全部为 GET，共 **10 个 Controller 映射**，其中历史映射有 browse/downloads 两种取值（展开为 11 个访问路径）。没有新增写业务 API。

| 路径 | 权限 | 数据与限制 |
|---|---|---|
| /api/portal/courses | TEACHER/STUDENT | ACTIVE 课程与公开资源数，包含零资源课程 |
| /api/portal/courses/{id} | TEACHER/STUDENT | 启用课程及有关启用元素；非法 ID 400，不可访问 404 |
| /api/portal/ideological-topics | TEACHER/STUDENT | ACTIVE 元素及公开资源数，包含零资源元素 |
| /api/portal/ideological-topics/{id} | TEACHER/STUDENT | 启用元素及有关启用课程 |
| /api/portal/resources/{id} | TEACHER/STUDENT | 计数、固定课程/元素关联；不额外记浏览 |
| /api/history/{kind} | TEACHER/STUDENT | kind=browse/downloads；本人分页，size 1..100 |
| /api/teacher/resource-dashboard | TEACHER | 本人状态数、最近/驳回/已发布资源各至多 5 条 |
| /api/teacher/resource-presentations?ids=... | TEACHER | 本人资源批量展示信息，至多 100 ID；他人资源 404 |
| /api/admin/published-resources | ADMIN | 已发布台账、组合筛选、分页，size 1..100 |
| /api/admin/review-overview | ADMIN | 最近 5 条真实待审核资源 |

新增 ResourceReadModels、ResourcePortalController/Service/Repository，URL、方法及 Service 三层核对角色。只读 REPEATABLE_READ，全部请求值使用参数绑定；固定表/列片段由内部逻辑选择。计数对一批资源执行 3 次聚合，不逐行查询；关联元素和审核摘要也批量读取。普通展示 VO 不返回文件存储键、绝对路径、密码或审核内部字段。公开详情原 GET 仍负责唯一一次浏览事件，新展示读取不记事件。

## 11. 已知限制与交付边界

- 浏览器实际上传通过文件选择器；拖拽处理已实现，但未自动化操作操作系统级文件拖拽，不宣称该路径已实测。
