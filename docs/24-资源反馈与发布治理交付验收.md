## 交付范围

## 真实数据库与接口

本机MySQL实查版本8.0.39，management-system共15表。既有004增量已实施，本次没有再次迁移或回滚数据库：

| 对象 | 实际结构要点 |
|---|---|
| teaching_resource.withdrawn_at | DATETIME(3)，可空；不改变原审核状态 |
| publication_event | 6字段；resource_id、actor_id为外键；WITHDRAW/RESTORE、原因、真实发生时间 |
| resource_feedback | 10字段；资源、反馈人、类型、说明、状态、回复、处理人/时间、创建时间 |

当前结构与database/schema.sql、database/migrations/004-resource-governance.sql及docs/06一致；既有13表加本阶段两表共15表。所有历史外键保留，未增加资源物理删除接口。

新增接口：

| 方法 | 路径 | 身份 |
|---|---|---|
| GET | /api/admin/published-resources/{id}/publication | ADMIN |
| POST | /api/admin/published-resources/{id}/withdraw | ADMIN，原因必填 |
| POST | /api/admin/published-resources/{id}/restore | ADMIN，原附件校验 |
| POST | /api/resources/{id}/feedback | TEACHER/STUDENT |
| GET | /api/resource-feedback/mine | TEACHER/STUDENT，本人 |
| GET | /api/admin/resource-feedback | ADMIN |
| POST | /api/admin/resource-feedback/{id}/handle | ADMIN，处理说明必填 |

台账原GET接口另接受ALL/LIVE/WITHDRAWN发布筛选。所有写请求沿用Session与CSRF，角色同时由后端校验。

## 今日联网研究与取舍

本轮新增核验下面3个一手页面，覆盖教育资源治理、状态视觉、反馈消息。它们是设计依据，并不证明本系统具备相同规模、政策或教学效果。

| 一手来源 | 核验内容 | 项目差距与取舍 |
|---|---|---|
| [OER Commons Collection Policy](https://help.oercommons.org/support/solutions/articles/42000107074-oer-commons-collection-policy) | 页面标注2026-07-24修改；分别描述资源维护、内容复核请求与最终决定；复核期间不当然移除材料 | 支持将反馈结案与发布治理分开，已落实此闭环。该平台匿名开放、版权与多级复核政策不照搬到本系统；不增加多级工单或自动下架 |
| [GOV.UK Tag](https://design-system.service.gov.uk/components/tag/) | 状态标签使用描述性文字，与操作按钮区分；尽量使用少量必要状态 | 本轮区分“审核通过”与“已下架”，不让标签承担操作。保留真实按钮和原因区，不增加新颜色主题。当前反馈表窄屏依赖局部横向滚动，是可继续评估的展示差距 |
| [GOV.UK Notification banner](https://design-system.service.gov.uk/components/notification-banner/) | 提示应克制；当前任务直接相关信息放主体；校验错误不应依赖泛化通知横幅 | 保留就地成功/错误提示和正式回复。现有全局成功toast与局部成功说明有重复，可列入后续精简候选，本次不借机改全局API反馈机制 |
