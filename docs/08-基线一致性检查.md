## 决策记录

1. 审核通过即内部发布；公开可见条件同时检查 `APPROVED`、`deleted_at IS NULL` 和 `published_at IS NOT NULL`，避免把“已审核”与“可访问”混同。
2. 教师仅软删除本人草稿或驳回资源；管理员下架、撤回及版本管理不在当前范围内。所有外键限制物理删除，审核记录不删。
3. 已通过资源的教师侧直接编辑暂不开放，否则需要新增版本与重新审核语义；该事项是后续可能的需求变更，不属于当前实现范围。
4. 资源分类独立为管理员维护的基础数据，用于统一检索和统计口径；不扩展为自由标签或复杂分类树。
5. Spring Security 用于后续认证授权模块；骨架仅验证最短技术链路，不把公开连通性接口误当成正式安全方案。

## 尚需在开发中验证的事项

- 本机现有 3306 端口 MySQL 服务的项目账号尚未配置；骨架实连验证使用仅绑定 127.0.0.1 的独立 MySQL 8.0.39 临时实例。进入日常开发前需为现有服务配置项目专用数据库账号。
- 可预览文件类型和最大上传体积应在文件模块实施时根据可用环境确定并形成测试用例，现阶段不臆定性能指标。
- 每阶段应检查实际代码是否仍满足本表映射；新增业务功能须先核对任务书和开题报告。

## 第六阶段最终核对

上述待验证事项是骨架阶段历史记录；现已实际连接本机MySQL80的management-system库，上传白名单和20 MiB上限已有验证。任务书和开题报告本轮只读、不修改。

FR-01—10、UC-01—17与当前角色/状态规则、11表设计、接口及页面逐项对应。实际采用basedata复用三种基础数据，resource落实草稿/审核/公开使用，statistics负责只读聚合，不因初期包名建议增加无用层。发现旧UC-08/状态图/本文件有管理员下架分支，已仅修正文档、移除越范围设计，没有实现下架代码；统计未实现等旧现状已以阶段同步说明覆盖。真实验收结果与限制统一记录于docs/15。
